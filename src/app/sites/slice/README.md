
# Refocus

A client-side video zoom editor.

## Features
- **Upload**: Drag & drop or select video.
- **Timeline**: Seek, play, pause.
- **Keyframes**: Add zoom points, edit scale/position.
- **Interpolation**: Smooth linear interpolation between keyframes.

## Usage
1. Upload a video (MP4/MOV).
2. Scrub to a timestamp.
3. Click "Add Keyframe".
4. Adjust Scale/Position in the right panel.
5. Scrub/Play to see the effect.
