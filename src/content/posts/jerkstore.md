We've been hard at work building **Jerkstore**, a new application designed for one simple purpose: generating creative, biting, and sometimes downright absurd insults. It's been a fun journey integrating several powerful technologies mostly just to see what kind of insults an AI can come up with when given the right prodding.

## The Stack

We built Jerkstore using a modern stack optimized for speed and verified "chaos":
*   **Next.js 15 (App Router)**: For the core framework.
*   **Vercel**: For hosting and edge middleware.
*   **DeepSeek V3**: The brain behind the burns.
*   **OpenAI Moderation API**: The responsible adult in the room.
*   **Stripe**: For the "Diamond Hands" who want premium insults.

***Disclaimer**: The content generated by Jerkstore is for entertainment purposes only. We have guardrails in place, but AI can be unpredictable. Don't take it too seriously!*

## DeepSeek Integration: Why Not GPT-4?

We're using DeepSeek's API to power the core insult generation. Why? Two reasons: **Cost** and **Creativity**.

DeepSeek offers a great balance of creativity and cost-effectiveness. We found that for creative writing tasks like generating insults, it often produces results that feel less "corporate sanitized" than other models, while still adhering to instructions.

We prompt it to be witty and biting without crossing into hate speech. The prompt engineering here was key—finding the line between "funny roast" and "mean spirit" is harder than it looks. We use a high temperature setting (around 0.8) to encourage variety in the insults.

## Safety First: OpenAI Moderation

To ensure our generated content remains safe and fun, we've integrated [OpenAI's Moderation API](https://platform.openai.com/docs/guides/moderation).

Every generated insult touches this API *before* being shown to the user. This helps us filter out anything that violates safety policies, keeping the app friendly (well, as friendly as an insult app can be!). If the moderation API flags a response, we silently discard it and try again, ensuring the user never sees something truly offensive.

## Multi-Tenant Architecture on Vercel

Under the hood, Jerkstore isn't just a standalone app—it's part of a larger **multi-tenant React application**. built on **Next.js** and deployed on **Vercel**.

We use Next.js Middleware to rewrite incoming requests based on the hostname.
*   `proximalcoast.com` -> Renders the main portfolio/blog.
*   `jerkstore.app` -> Renders the Jerkstore application.

For local development, we use `lvh.me` (which resolves `anything.lvh.me` to `127.0.0.1`). This lets us test subdomain routing locally without messing with `/etc/hosts`. For example, we access `jerkstore.lvh.me:3000` to test the Jerkstore site locally.

This setup allows us to host multiple sites from a single codebase (a "monorepo" of sorts, but without the tooling overhead), sharing UI components (like our button and card styles) and utility functions while maintaining distinct identities. It's a powerful pattern that lets us ship faster.

## Stripe for Payments

We're setting up Stripe to handle support for the app. It's the industry standard for specific reasons—easy to set up, great documentation, and a robust test mode that makes development a breeze.

We implemented a "Diamond Hands" tier for $5/mo that unlocks:
1.  **Unlimited Insults**: No daily caps.
2.  **Multi-Language Support**: Get roasted in French, Spanish, or Klingon.
3.  **Priority Queuing**: Skip the line when the servers are busy.

The checkout flow is handled via Stripe Checkout, redirecting users back to the app upon success. It handles all the PCI compliance and tax complexity so we don't have to.
